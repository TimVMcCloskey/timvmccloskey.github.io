CastVR

CAD-to-VR Engineering Visualization Engine · C · OpenGL · OpenXR · Meta Quest 3
CastVR mechanical pipe-vise assembly rendered by the custom C/OpenGL/OpenXR visualization engine.

Project Overview

A custom real-time engineering visualization engine built from the graphics API up.

CastVR imports multi-part mechanical assemblies from FreeCAD and presents them in immersive VR for inspection, exploded/assembled visualization, interactive manipulation, and mechanical motion. The application is built without Unity, Unreal, a game engine, or a VR framework.

What I Built

  • C/OpenGL/OpenXR rendering and VR application stack
  • FreeCAD mechanical-assembly import through Assimp
  • JSON-driven scene graph for multi-part assemblies
  • Cook-Torrance physically based rendering with procedural image-based lighting
  • Stereoscopic headset rendering plus a stabilized PC mirror view
  • Quest 3 controller ray picking and 6DOF interaction
  • Explode / assemble states and component inspection
  • Kinematic pipe-vise linkage driven by VR controller input

Why It Matters

CastVR demonstrates low-level graphics and XR engineering below the game-engine layer. It combines real-time rendering, immersive interaction, scene organization, and mechanical visualization in a system intended for technical and engineering use.

Engineering Visualization Value

  • Inspect assembly relationships at human scale
  • Separate and examine individual mechanical parts
  • Visualize assembly and disassembly sequences
  • Demonstrate linkage and mechanism motion interactively
  • Provide a foundation for design-review features such as metadata, dimensions, isolation, and section views
